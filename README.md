# TravelHub

TravelHub, yaz stajı başvurum kapsamında geliştirdiğim modern bir seyahat rehberi web uygulamasıdır.

Bu proje ile kullanıcıların ülkeleri keşfetmesini, detaylı ülke bilgilerine ulaşmasını, hava durumunu görüntülemesini, döviz çevirisi yapmasını ve favori ülkelerini kaydetmesini sağlayan kullanışlı bir platform geliştirmeyi amaçladım.

## Özellikler

- Ülkeleri listeleme
- Ülke adına göre arama
- Kıtaya göre filtreleme
- Detaylı ülke bilgi sayfası
- Güncel hava durumu bilgileri
- Döviz çevirici
- Favori ülkeleri kaydetme (LocalStorage)
- Karanlık / Aydınlık tema desteği
- Responsive tasarım
- Skeleton Loading ekranları
- Toast bildirim sistemi

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6)
- REST Countries API
- Open-Meteo API
- ExchangeRate API
- Font Awesome

## Kurulum

Projeyi klonlayın:

```bash
git clone https://github.com/Yxmann/TravelHub.git
```

Proje klasörüne geçin:

```bash
cd TravelHub
```

Ardından Live Server ile çalıştırabilir veya `index.html` dosyasını tarayıcı üzerinden açabilirsiniz.

Bu proje, yaz stajı başvurum kapsamında modern web geliştirme konusundaki bilgi ve becerilerimi geliştirmek amacıyla hazırlanmıştır.

Projeyi geliştirirken API kullanımı, responsive tasarım, kullanıcı deneyimi ve JavaScript ile dinamik içerik oluşturma konularına odaklandım.
